SEO friendly-Responsive Web Pages with Meta-Tags

"I am into HTML Body Play with before & After"

  • '<' meta charset="UTF-8" '>' → Added into head tag to support all standard Keyboards charset.
  • '<' meta name="viewport" content="width=device-width, initial-scale=1.0" '>' → Added to make the web page responsive in nature.
  • '<' meta http-equiv="refresh" content="2" '>' → Web Page will get refreshed every 2 seconds, its not recommended (not safe operation) to use if required based on the requirment.
  • '<' meta name="keywords" content="Full Stack FrontEnd , Web-Dev, SEO, Responsive" '>' → VVIP/most important to get higher SEO ranking by search engine get the search result as top most.
  • '<' meta name="description" content="This is SEO friendly-Responsive web page Meta-Tags intro.." '>' → important to get higher SEO ranking by search engine and the value of the 'content' will populate as(description) search result to identify the website.
  • '<' meta name="author" content="Abhinay Lunawat" '>' → Userfull for Developer point of view to represent the owner/creator of the Web page.
